Inline note box in three tones — info (sky), warning (amber), rule (teal).

```jsx
<Callout tone="warning">لا تُشغّل <span className="tok-code">npm run build</span> قبل حفظ الملفات.</Callout>
```

Border sits on the **inline-start** edge, so it mirrors with direction. One callout per slide at most — two means the slide has two ideas.
