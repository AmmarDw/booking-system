Line-icon wrapper around the Lucide set — the only icon source in this system (2px stroke, rounded caps, matching the monogram geometry).

```jsx
<Icon name="clock" size={20} />
```

Requires `<script src="https://unpkg.com/lucide@0.446.0/dist/umd/lucide.js"></script>` on the page. Colour comes from `currentColor` — set it on the parent. Renders an empty box if Lucide has not loaded.
